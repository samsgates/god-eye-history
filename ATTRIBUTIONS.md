# Attributions

`god-eye-history` is an independent derivative implementation inspired by the open-source God's Eye View project architecture.

Core mapping:
- CesiumJS
- OpenStreetMap contributors
- OpenHistoricalMap contributors

Historical sources may include:
- Wikidata / Wikimedia Foundation
- Wikimedia Commons contributors
- Europeana and participating institutions

Live context may include:
- USGS
- OpenSky Network
- Transport for London
- NASA FIRMS
- TomTom

The UI must display attribution required by the active provider. Every historical media object should retain its individual rights/license metadata.
