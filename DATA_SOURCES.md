# Data Sources

| Source | Purpose | Notes |
|---|---|---|
| OpenStreetMap Nominatim | place search / reverse geocoding | Follow Nominatim usage policy in production. Run your own geocoder at scale. |
| Wikidata Query Service | structured historical events | CC0 data. Respect WDQS usage limits. |
| Wikipedia | contextual summaries | Content licensing/attribution applies. |
| Wikimedia Commons | historical media metadata | Each file has its own license. |
| OpenHistoricalMap | historical basemap/data | ODbL-derived project terms and attribution requirements apply. Verify tile policy for production. |
| Europeana | cultural heritage records | API terms and each object's rights statement apply. |
| USGS | current earthquakes | Public government source. |
| OpenSky | aircraft | Provider terms/rate limits apply. |
| TfL | London JamCam metadata | TfL terms apply. |
| NASA FIRMS | fire compatibility | Requires map key and terms. |
| TomTom | traffic compatibility | Commercial key/license. |

Never assume the MIT code license applies to third-party datasets, imagery, models, map tiles, photographs, or archival material.
